# 🍀 Lucky Dangle

A customizable desktop charm application built with Python and PyQt6.

## ✨ Features

- 🍀 Multiple built-in charms
- 🖼️ Upload your own charm image
- 🖱️ Drag the charm anywhere on the screen
- 🔄 Smooth swinging animation
- 📌 Always-on-top desktop widget
- 🖱️ Right-click menu
- 💻 Lightweight desktop application

## 🛠️ Technologies

- Python
- PyQt6
- Qt GUI
- Basic physics-based animation
